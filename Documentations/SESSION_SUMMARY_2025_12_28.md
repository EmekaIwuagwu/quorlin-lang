## 🆕 Cardano/Aiken Backend

### Overview

Cardano smart contracts use a UTXO model different from account-based chains. The new Aiken backend generates:

- **Datum Types** - Contract state stored with UTXOs
- **Redeemer Types** - Actions that can be performed on the contract
- **Validators** - The main contract logic in Aiken syntax
- **View Functions** - Off-chain query helpers

### Example Output

For a simple counter contract, the Aiken output includes:

```aiken
// Generated by Quorlin Compiler
// Target: Cardano/Aiken

use aiken/hash.{Blake2b_224, Hash}
use aiken/transaction.{ScriptContext}

/// Datum for Counter validator
type CounterDatum {
    count: Int,
}

/// Redeemer (actions) for Counter validator
type CounterRedeemer {
    Increment
    Reset
}

/// Main validator for Counter
validator counter {
    spend(datum: Option<CounterDatum>, redeemer: CounterRedeemer, ctx: ScriptContext) {
        expect Some(d) = datum
        when redeemer is {
            Increment -> {
                // State update: d.count = (d.count + 1)
                True
            }
            Reset -> {
                // State update: d.count = 0
                True
            }
        }
    }
}

/// View function: get_count
fn get_count(datum: CounterDatum) -> Int {
    datum.count
}
```

### Bootstrap Minimal Compiler

A simplified, bootstrap-compatible version was created that:
- Uses only syntax currently supported by the Rust compiler
- Demonstrates the compiler architecture (Lexer → Parser → Codegen)
- Compiles successfully to all 6 blockchain targets
- Located at: `compiler/bootstrap_minimal.ql`

### Self-Hosting Roadmap Status

| Phase | Description | Status |
|-------|-------------|--------|
| Phase 1 | Foundation (Specs, AST, Tests) | 40% |
| Phase 2 | Frontend (Lexer, Parser) | Written but needs Systems Quorlin features |
| Phase 3 | Middle-End (IR Generation) | Written |
| Phase 4 | Backends | Written |
| Phase 5 | Bootstrap | Pending |
| Phase 6 | Testing | In progress |
| Phase 7 | Rust Independence | Pending |

### Key Finding

The full self-hosting compiler components are written in "Systems Quorlin" which includes advanced features not yet implemented in the Rust bootstrap compiler:

- `?` operator for error propagation
- `//` style comments (vs `#`)
- f-strings (`f"..."`)
- Generic types (`Vec[T]`, `HashMap[K,V]`)
- Pattern matching (`match` expressions)
- `Result[T, E]` and `Option[T]` types
- Traits and implementations

**Next step:** Extend the Rust lexer/parser to support these Systems Quorlin features, enabling full self-compilation.
